## Overview

This project analyzes global e-commerce transaction data to surface trends
in sales performance, customer behavior, product category growth, and
regional demand — presented through an interactive web dashboard.

## Getting started

```bash
git clone https://github.com/inanbiswas10/Global_E-Commerce_Intelligence_Engine.git
cd Global_E-Commerce_Intelligence_Engine
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app/main.py
```
